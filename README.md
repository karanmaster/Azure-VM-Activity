# Azure VM Creation

This project demonstrates the step-by-step process of creating a Virtual Machine in Azure.

## Steps Included:
1. Setting up an Azure account.
2. Creating a resource group.
3. Configuring the VM size and type.
4. Setting up networking and security.
5. Verifying the VM creation.

## Screenshots:
Screenshots of each step are stored in the `screenshots` folder for reference.

## Purpose:
The purpose of this project is to learn how to create and manage virtual machines on Azure.

## Tools Used:
- Microsoft Azure Portal
- PowerShell (optional for automation)
- Git (for tracking and collaboration)
